# Day08 News Crawl Task Files

Copy these files into the root of your repository.

## Files included

- `data/landing/news/news_urls.txt`
- `src/task2_crawl_news.py`
- `src/task3_convert_news_markdown.py`

## Install

```bash
pip install crawl4ai beautifulsoup4
```

```bash
python src/task2_crawl_news.py
```

## Run Task 3 for news

